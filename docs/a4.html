Core Deliverables

  • HTML → text extraction from Common Crawl (extract main content, remove boilerplate)（从 Common Crawl 提取正文，去除模板内容）
  • Quality classifier — train a classifier to identify high-quality text（训练分类器识别高质量文本）
  • Toxicity classifier — train a classifier to filter harmful content（训练分类器过滤有害内容）
  • MinHash deduplication — efficiently find and remove near-duplicate documents（高效发现和移除近重复文档）
  • Data mixing — optimize the ratio of different data sources（优化不同数据来源的配比）
