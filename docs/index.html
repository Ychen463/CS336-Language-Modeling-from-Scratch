Lecture Notes

LECTURE 01

Overview & Tokenization

Course intro, BPE tokenizer, Unicode, bytes, compression ratio.

 LECTURE 02

PyTorch & Resource Accounting

Einops, FLOPs counting, memory estimation, arithmetic intensity.

 LECTURE 03

Architectures & Hyperparameters

Transformer variants, activation functions, positional encodings, normalization.

 LECTURE 04

Attention Alternatives & MoE

GQA, MLA, linear attention, Mamba, mixture of experts, load balancing.

 LECTURE 05

GPUs & TPUs

GPU architecture, memory hierarchy, SMs, warps, roofline analysis.

 LECTURE 06

Kernels & Triton

Custom kernels, operator fusion, tiling, FlashAttention, Triton programming.

 LECTURE 07

Parallelism I

Data parallelism, collective operations, all-reduce, gradient accumulation.

 LECTURE 08

Parallelism II

Tensor, pipeline, sequence, expert parallelism. ZeRO, FSDP.

 LECTURE 09

Scaling Laws I

Kaplan scaling laws, Chinchilla, ISOFLOP curves, compute-optimal training.

 LECTURE 10

Inference

Prefill vs decode, KV cache, speculative decoding, quantization.

 LECTURE 11

Scaling Laws II

Hyperparameter transfer, muP, scaling recipes, predictability.

 LECTURE 12

Evaluation

Perplexity, benchmarks, contamination, LM-as-judge, leaderboards.

 LECTURE 13

Data: Sources & Datasets

Common Crawl, The Pile, data sourcing, copyright, licensing.

 LECTURE 14

Data: Processing

HTML extraction, quality filtering, deduplication, MinHash, data mixing.

 LECTURE 15

SFT & RLHF

Supervised fine-tuning, reward models, PPO, InstructGPT pipeline.

 LECTURE 16

RLVR

DPO, GRPO, verifiable rewards, reasoning RL.

 LECTURE 17

Multimodality

Vision encoders, CLIP, visual language models, tokenization for images.
