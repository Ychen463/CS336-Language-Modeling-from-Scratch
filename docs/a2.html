Key Concepts

Notes

1. Core Deliverables

  • Fused RMSNorm kernel in Triton — combine normalization operations into a single GPU kernel（Triton 融合 RMSNorm 核：将归一化操作合并为一个 GPU 核）
  • Distributed data parallel (DDP) — synchronize gradients across multiple GPUs via all-reduce（分布式数据并行：通过 all-reduce 在多 GPU 间同步梯度）
  • Optimizer state sharding (ZeRO-1) — each GPU only stores a shard of optimizer states（优化器状态分片：每个 GPU 只存储一部分优化器状态）
  • Benchmarking and profiling — use Nsight Systems to see real GPU utilization（用 Nsight Systems 查看实际 GPU 利用率）
