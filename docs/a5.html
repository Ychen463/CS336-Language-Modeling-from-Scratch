Core Deliverables

  • DPO (Direct Preference Optimization) — learn from pairs of preferred/rejected responses without training a separate reward model（从偏好/拒绝回复对中学习，无需单独训练奖励模型）
  • GRPO (Group Relative Policy Optimization) — generate groups of responses, rank them, update policy to prefer better ones. No value function needed（生成回复组，排序，更新策略偏好更好的回复。不需要价值函数）
